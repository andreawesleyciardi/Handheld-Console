This is the first Retro-Go adaptation of the Bounitos Midnight visual style.

The theme currently keeps Retro-Go's default images and layout while applying a
Midnight-inspired blue, charcoal, white, and cool-gray palette. Images will be
adapted in a later step.

The source visual reference is the Bounitos Midnight Recalbox theme:

https://media.recalbox.com/hub/-/raw/main/bounitos-midnight/bounitos-midnight.zip

This folder follows Retro-Go's external theme format. The `theme.json` colors
are RGB565 values and are loaded from the SD card at runtime.
